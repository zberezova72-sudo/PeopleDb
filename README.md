# Лабораторна робота з ООП — робота з файлами

**Варіант №3.** Сутності: `Student`, `Musician`, `Pilot`. Додаткове вміння: катання на ковзанах (`Skate`).
Завдання варіанту: порахувати студенток 1-го курсу, які проживають у гуртожитку, отримавши їхні дані з файлу.


## Структура рішення

| Проект | Призначення |
|---|---|
| `src/FileStorage` | **Лише** читання/запис файлу через потоки (`FileStream`, `StreamReader`, `StreamWriter`). Жодної предметної області та консолі. |
| `src/PeopleDb.Core` | Сутності, вміння (інтерфейси), специфікації, дескриптори (відображення на файл), репозиторій, регулярні вирази. Без консолі. |
| `src/PeopleDb.App` | `ConsoleMenu` (весь ввід/вивід), корінь композиції `Program.cs`, демо-дані. |

Діаграма класів: [docs/ClassDiagram.md](docs/ClassDiagram.md).

## Формат файлу (один файл для всіх типів)

```
Student ОксанаКоваленко
{ "firstname": "Оксана",
"lastname": "Коваленко",
"studentId": "КВ123456",
"course": "1",
"gender": "Ж",
"residence": "5.312",
"lessons": "0",
"skatingSessions": "0"};
Pilot ВікторГончар
{ "firstname": "Віктор", ... };
```

## Сутності та валідація (регулярні вирази — `Core/Validation/Rules.cs`)

| Тип | Обов'язкові атрибути | Формат |
|---|---|---|
| Student | прізвище, ім'я, студентський квиток, курс, стать, місце проживання | квиток `КВ123456` (2 літери + 6 цифр); курс 1–6; стать Ч/Ж; гуртожиток `номер.кімната` (напр. `5.312`) або адреса |
| Musician | прізвище, ім'я, `musicianId`, `instrument` | `MU100001` |
| Pilot | прізвище, ім'я, `licenseNumber` | `PL-200001` |
